# Cour de Miracles

Portale statico per raccogliere progetti, applicazioni e documenti di `sc4tto`.

## Struttura

- `index.html`: pagina principale;
- `progetti.html`: archivio dei progetti;
- `documenti.html`: raccolta dei documenti;
- `data/projects.json`: dati centralizzati delle schede;
- `js/projects.js`: generazione delle schede;
- `css/style.css`: stile di base, da sviluppare in una fase successiva.

La prima versione privilegia struttura, navigazione e collegamenti. L’identità grafica sarà sviluppata successivamente.
